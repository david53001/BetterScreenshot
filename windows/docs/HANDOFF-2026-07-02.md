## 3. Phases DONE ✅ (1–6)

Each phase was built TDD-first for pure logic and verified by build + app-launch for UI.

- **Phase 0 — Scaffold.** .NET 9 solution `windows/BetterScreenshot.sln`, 8 projects
  (`Core`, `Capture`, `Editor`, `History`, `Recording` = `net9.0`; `Platform`, `App` =
  `net9.0-windows...`; plus the `tests` project). Windowless WPF tray shell, PerMonitorV2 manifest.
- **Phase 1 — Pure-logic core (104 tests).** Geometry (`PxRect/PxPoint/PxSize`, top-left coords),
  crop, filename, hotkey model (Ctrl+Shift+4/5/6/7/8 defaults), overlay positioning, OCR/QR result
  model, capture settings, window-pick hit-test, annotation model + `EditorDocument`, arrow geometry,
  history index/entry/restore-stack, recording config/state/pause-timeline/GIF timing, pin geometry,
  redactor (blur/pixelate buffer logic).
- **Phase 2 — Windows platform integration (Platform lib).** Screen enumeration + DPI, still capture
  (GDI BitBlt / PrintWindow), window picking (Win32 z-order enum), clipboard + PNG/JPG encode, OCR
  (`Windows.Media.Ocr`) + QR (ZXing), global hotkey host (`RegisterHotKey` on a hidden HwndSource),
  ffmpeg runner + availability, global input hooks (`WH_MOUSE_LL`/`WH_KEYBOARD_LL`) + keystroke glyphs.
- **Phase 3 — App shell + capture flow.** JSON settings store (keys 1:1 with mac), WinForms tray +
  full menu, hotkey wiring → dispatch, `CaptureCoordinator` (area/fullscreen/window/text → route by
  after-capture setting → save/copy), first-run welcome window, settings window (General/Shortcuts/
  Recording tabs + live shortcut recorder).
- **Phase 4 — Overlays.** Area-selection overlay (physical-pixel positioning), Quick Access card +
  stack (≤3 cards, drag-to-export), pin-to-screen panels (drag/zoom/multi-pin), Capture-Text HUD,
  interactive window picker.
- **Phase 5 — Annotation editor (157 tests at completion).** Editor window + custom canvas render,
  drawing tools (arrow/line/rect/filled/ellipse/text/redact/crop/select), color+size inspector,
  snapshot undo/redo, **sticky style** (last-used stroke/text color+size persisted), bottom-bar
  Copy/Save/Stack/Done; reachable from the Quick Access "Edit" button.
- **Phase 6 — Capture history (197 tests).** File-backed `HistoryStore` (owned PNG copies +
  JPEG thumbnails + `history.json`, 30-day + count-cap + missing-file pruning at load; recordings
  stored by reference and never deleted), `ThumbnailRenderer` (≤400px JPEG q0.8), `HistoryService`
  facade (record on save/overlay, restore-recently-closed LIFO, copy/reveal/delete/clear-all),
  `RestoreStack.PopRestorable`, `HistoryDateFormat.Relative` ("2h ago"), and the **History window**
  (dark thumbnail grid, camera/film badges, relative date, action bar, double-click open). Wired into
  the tray "History…" and "Restore Recently Closed" commands.
